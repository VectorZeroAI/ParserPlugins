# ParserPlugins
The plugin parsers for ai-diagnos-lsp cross file analysis. 

You can submit your plugin parsers here. 

## Structure

There are 2 directories:
1. Vibed
2. Community

The Vibed directory is where I put the parsers I Vibecoded. 
I would argue that an import resolving parser is something an AI can write reasonably good. 
At least it can write it so its not a net negative. 

Community is where I put parsers the all of you wanted to share.

> I am not to be held accountable for any crap the community parsers do. Use on your own risk. 

## Contributing
